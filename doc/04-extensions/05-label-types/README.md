# Label Types

[Labels](../../01-model/03-elements-sub.md#labels) with a predefined meaning use the reserved
`ocm.software` DNS prefix (see [Label Types](../../01-model/07-extensions.md#label-types)).
The following labels are specified by the Open Component Model.

| LABEL NAME                                                   | VERSION    | DESCRIPTION                                                               |
|--------------------------------------------------------------|------------|---------------------------------------------------------------------------|
| [`ocm.software/artifact-references`](artifact-references.md) | `v1alpha1` | Expresses a cross-artifact relationship within the same component version |
